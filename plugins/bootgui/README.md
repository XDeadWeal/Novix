# BootGUI Plugin

A graphical user interface plugin for Novix OS that provides:
- Desktop environment
- Taskbar with clock
- Start menu
- Basic window management

## Installation

```bash
xudo install bootgui
```

## Usage

After installation, run:
```bash
bootgui
```

Or start automatically at boot by adding to your startup scripts.

## Features

- **Taskbar**: Shows running applications and system clock
- **Start Menu**: Access applications and system settings
- **Desktop**: Clean workspace for your applications

## Configuration

Edit /etc/bootgui/bootgui.conf to customize:
- Taskbar position (top/bottom)
- Taskbar color
- Start menu items
- Auto-start settings
